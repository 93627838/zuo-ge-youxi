# 做个游戏 · zuo-ge-youxi

一个用 C++ 开发的**控制台爬塔 Roguelike（肉鸽）游戏**。
玩家登上一座神秘的塔，逐层挑战战斗、精英、事件与宝箱房间，击败每层的 BOSS 后上楼。

## 🎮 当前实现

- **玩法核心**：房间导航 + 战斗/事件/宝箱/商店 + 楼层推进。
  打败当前层 BOSS 后输入 `up` 上楼，进入下一层。
- **已完成 2 层关卡**：
  - 第 1 层「灰烬平原」—— 烬骨塔的第一层，BOSS「战神·烬骨的皮肤」
  - 第 2 层「倒悬之海」—— 倒悬的海底世界，BOSS「深母之泪」
- **架构**（`src/`）：
  - `Room.h` —— 房间数据与奖励结构、房间类型（起点/战斗/精英/首领/宝藏/事件/商店）
  - `FloorBuilder` —— 逐层地图/关卡构建（`buildFloor1()`…，头文件已预留到第 7 层）
  - `FloorManager` —— 楼层加载、玩家导航、通关判定、上楼逻辑
  - `main.cpp` —— 主循环：清屏、显示房间与旁白、读取输入、结算奖励

## 🛠 环境与运行

- **语言/标准**：C++20
- **工具链**：Visual Studio 2022（v143），或任意支持 C++20 的编译器
- **打开方式**：用 Visual Studio 打开根目录的 `zuo-ge-youxi.slnx`，选 `x64`/`Debug` 生成并运行；
  或命令行（如 MSVC / g++）直接编译 `src/` 下的 3 个 `.cpp`。
