# 逆神者之塔 · zuo-ge-youxi

一个用 C++ 开发的**控制台肉鸽（Roguelike）爬塔游戏**。

> 你不是英雄，你是被塔"选中"的倒霉蛋。一块神骸碎片刺入身体，不爬塔就会在三个月内被吞噬成半神半尸的怪物。
> 登上的每一层都对应一位主神的一部分躯体与权柄，逐层挑战战斗、精英、事件与宝藏房间，击败每层的 BOSS 后方能上楼。
> 直到第七层「空王座」——那里坐着的，是"如果从一开始就选择另一条路"的你。

## 🎮 当前实现（v1.2 · 地图系统）

- **程序化地图生成**：每层地图由 `FloorGenerator` 按 `MapTemplates` 中抽选的拓扑模板自动铺成，节点类型（战斗/精英/事件/宝箱/商店/Boss）按概率与"保底"规则分配，配合地图种子可复现。
- **地图可视化**：游戏内输入 `map` 可绘制整层 ASCII 地图（`@` 为玩家当前位置，颜色区分房间类型）。
- **楼层推进**：击败当前层 BOSS 后输入 `up` 上楼，目前生成器可无限生成楼层。
- **7 层世界观框架**：`FloorBuilder` 内含七层手写剧情房间（灰烬平原 → 倒悬海 → 黄金迷宫 → 低语森林 → 熔炉胸腔 → 镜面颅腔 → 空王座），作为"经典剧情模式"的内容储备（详见下方规划）。

## 🧩 架构（`src/`）

| 文件 | 职责 |
|------|------|
| `Room.h` | 房间数据与奖励结构、房间类型枚举（起点/战斗/精英/首领/宝藏/事件/商店） |
| `MapTemplates.h` | 4 种地图拓扑模板（直链分支 / 双叉树 / 菱形环 / 3×3 网格）+ 按层选池 |
| `FloorGenerator.h/.cpp` | ★程序化生成核心：抽模板 → 分配节点类型 → 填名字/描述/奖励（当前主生效路径） |
| `FloorManager.h/.cpp` | 楼层管家：加载楼层、玩家导航、通关判定、上楼逻辑、`drawMap` 绘图 |
| `FloorBuilder.h/.cpp` | 七层手写世界观房间（含"空王座六问"），经典剧情模式的内容源（当前未接入生成主链） |
| `main.cpp` | 主循环：读种子、显示房间与旁白、读取输入、结算奖励、绘制地图 |

> ⚠️ **当前架构注意**：运行时实际由 `FloorGenerator` 生成泛化随机地图；`FloorBuilder` 中精心设计的七层剧情房间尚未被调用（死代码）。后续"经典七层剧情模式"需将两者接起来。

## 🛠 环境与运行

- **语言/标准**：C++20
- **工具链**：Visual Studio 18（v145 / PlatformToolset），或任意支持 C++20 的编译器（g++/clang 亦可）
- **打开方式**：用 Visual Studio 打开根目录的 `zuo-ge-youxi.slnx`（或 `zuo-ge-youxi.vcxproj`），选 `x64` / `Debug` 生成并运行。
- **命令行编译（MSVC 示例）**：
  ```bat
  cl /std:c++20 /EHsc src\main.cpp src\FloorManager.cpp src\FloorBuilder.cpp src\FloorGenerator.cpp
  ```

### 操作指令（游戏内）
- 数字 `1` `2` … —— 选择可走的路径
- `map` —— 查看当前楼层地图
- `up` —— 击败 BOSS 后上楼
- `quit` —— 退出
